# Freetally — Privacy Policy

Public Privacy Policy page for the **Freetally** Android app, used as the privacy policy URL
required by Google Play Console.

- Live page (bilingual ES/EN): see GitHub Pages URL in the repo settings once enabled.
- Source text also available as plain Markdown: `privacy-policy.es.md`, `privacy-policy.en.md`.

This repository only contains the privacy policy for Freetally. It does not contain any app
source code.
